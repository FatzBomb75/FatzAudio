# Tutorials

Each tutorial builds one small, real thing from start to finish and links to the guides for the details. They use .NET; every call has a C twin named in the linked guide. Start with the console player and go on from there.

| Tutorial | You build | Uses |
|---|---|---|
| [Console player](console-player.md) | A command-line player that shows progress and stops at the end | Engine, output, stream, events |
| [WPF player](wpf-player.md) | A window with play, pause, a seek bar, volume, tags, a level meter | Marshalling events, seek, levels, tags |
| [Karaoke app](karaoke-app.md) | CD+G and MIDI karaoke with tempo and key change | CD+G surface, lyric surface, tempo, pitch |
| [DJ app](dj-app.md) | Two decks, crossfader, headphone cue, a singer's microphone | DJ mixer, mics, analysis |
| [Radio recorder](radio-recorder.md) | Listen to a web radio and record it to MP3 or FLAC | Web streams, metadata, encoder |
| [Library scanner](library-scanner.md) | Read tags, loudness, BPM and key for a folder of music | Tags, loudness, analysis |
| [Video player audio (FFmpeg A/V sync)](ffmpeg-av-sync.md) | Audio that your video renderer follows | Packet streams, the clock |
| [Mobile setup](mobile-setup.md) | Android and iOS setup checklists | Platform notes |

More short recipes are in the [cookbook](../cookbook.md).
